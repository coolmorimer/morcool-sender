# Проверки предварительной версии 1.1

Дата: 6 ноября 2026 года. Проверки выполнены на изолированных эмуляторах с искусственными контактами, локальным HTTP-сервером и тестовыми веб-страницами. Пользовательский телефон не использовался для проверки новой версии и не обновлялся.

## Подтверждённые результаты

| Среда | Результат | Что проверялось |
| --- | --- | --- |
| Android 15 / API 35, x86-64 | 55 проверок пройдено | Адреса мессенджеров, хранение, защита токенов, фоновые API-очереди, контролируемые веб-страницы, чтение тестового контакта из Android Contacts |
| Android 8 / API 26, x86 | 54 проверки пройдено | Тот же основной набор; проверка с добавлением тестового контакта через shell identity выполнялась только на API 29+ |
| Интерфейс | Проверен | Основные экраны в светлой и тёмной теме, масштаб шрифта 1,3; закреплённые кнопки основных действий |

Дополнительно пройдены 123 JVM-проверки и 18 Node-проверок точного сопоставления адресов. Финальная сборка проверена после обновления интерфейса и проверки движка очереди.

### Очереди и сохранение данных

- Различаются телефон, личный адрес и Chat ID бота.
- Повтор контакта в одном списке не добавляется.
- Контакт бота может существовать без номера телефона.
- API-очередь продолжает работу, когда на основном экране эмулятора открыт «Домой».
- Успешный ответ API записывается с ID сообщения.
- Ответ 403 пропускает адресата, ответ 429 обрабатывает ожидание сервиса.
- Настройки паузы вместо пропуска и остановки при ограничении сервиса сохраняют строку в очереди.
- Подготовка веб-чата ограничена по времени; совпадение только отображаемого имени не разрешает отправку.
- Telegram-адреса и стоп-лист нормализуют регистр, а регистр непрозрачных ссылок MAX сохраняется.
- Потерянный ответ после начала запроса считается неопределённым.
- Остановка во время запроса не запускает следующего получателя.
- Токены проходят шифрование/чтение Android Keystore; открытый токен отсутствует в сохранённых настройках и резервной копии.

### Веб-механизм личных аккаунтов

На локальных тестовых страницах проверены поиск адресата, совпадение заголовка, заполнение текста, однократное нажатие, очистка поля и завершение, в том числе за экраном «Домой».

Это подтверждает механизм исполнения очереди, но не совместимость селекторов с текущими страницами настоящих мессенджеров. Вход и отправка через личные WhatsApp, Telegram и MAX в данной версии на настоящем аккаунте не подтверждены. В интерфейсе веб-режим обозначен как экспериментальный.

## Что не подтверждено

- Запуск на Android 6.0 / API 23: это заявленный минимум сборки, а не проверенная физическая модель.
- Работа на всех телефонах, оболочках, разрешениях экрана и версиях System WebView.
- Реальная отправка, получение, доставка и прочтение сообщений через новые транспорты.
- Длительная непрерывная работа, восстановление после принудительной остановки, поведение всех режимов энергосбережения.
- Реальные учётные данные, токены и личные веб-сессии не применялись в изолированных тестах.
